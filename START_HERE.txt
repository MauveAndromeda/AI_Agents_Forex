🚀 快速开始（3步）：

  步骤 1: 确认已解压到简单路径
          推荐: C:\AI_Agents_Forex
          避免: 包含括号或空格的复杂路径

  步骤 2: 双击运行 "一键安装运行.py"
          或在终端运行: python 一键安装运行.py

  步骤 3: 选择 [1] 真实回测 5 年增强版

  就这样！系统会自动：
  ✓ 安装所有依赖
  ✓ 检查环境
  ✓ 开始回测

🆘 遇到问题？

  问题: "找不到 Python"
  解决: 安装 Python 3.8+ https://www.python.org/downloads/

  问题: "缺少必要目录 src"
  解决: 重新下载完整的 ZIP 并完全解压

  问题: "No module named 'src.xxx'"
  解决: 已修复！重新下载最新 ZIP

  问题: API 密钥配置
  解决: 运行 check_api_key.py 诊断
