  AI Agents Forex - Forex Trading Backtest System
================================================================================

This is a forex trading backtest system with AI components.

Quick Start (2 steps):

  Step 1: Extract to a simple path
          Recommended: C:\AI_Agents_Forex
          Avoid: Paths with parentheses or spaces

  Step 2: Run "一键回测.py"
          Command: python 一键回测.py

  The system will:
  - Automatically install dependencies
  - Configure API key (optional)
  - Run complete backtest with real data
  - Generate detailed report

Common Issues:

  Issue: "Python not found"
  Fix: Install Python 3.8+ from https://www.python.org/downloads/

  Issue: "Missing src directory"
  Fix: Re-download complete ZIP and extract fully

  Issue: "No module named 'src.xxx'"
  Fix: Re-download latest ZIP (this has been fixed)

  Issue: API key configuration
  Fix: Run the script, it will guide you through API setup

  - Can use quantitative mode (no API key required, free)
  - Results saved in backtest_results/ directory
