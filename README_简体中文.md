# AI Agents Forex - 智能外汇交易回测系统

**完整的 AI 驱动外汇交易系统，支持 5 年真实数据回测**

---

## 📦 快速开始（ZIP 下载方式）

### 步骤 1: 下载项目

1. 访问 GitHub 仓库
2. 点击绿色的 **Code** 按钮
3. 选择 **Download ZIP**
4. 解压到任意目录

### 步骤 2: 安装依赖

在解压后的目录中打开终端（PowerShell 或 CMD）：

```bash
# Windows
pip install -r requirements.txt

# 或者自动安装（脚本会自动检测并安装）
python run_backtest.py
```

### 步骤 3: 运行回测（超简单！）

```bash
# 统一入口 - 推荐方式
python run_backtest.py
```

然后选择你想要的回测模式：

```
  [1] 🚀 真实回测 5 年增强版（推荐）
  [2] ⚡ 高速并发回测版
  [3] 📊 标准回测版
  [4] 🔍 检查 API 密钥配置
```

## 🎯 三种回测模式对比

### 模式 1: 真实回测 5 年增强版 ⭐推荐

**特点**：
- ✅ 支持最多 5 年真实 MT5 历史数据
- ✅ 智能自适应学习系统（渐进式学习）
- ✅ 详细调试日志（知道为什么信号被过滤）
- ✅ 改进的信号整合算法
- ✅ 自动回退到模拟数据（如果 MT5 不可用）

**适合场景**：
- 🎯 需要长期回测验证策略
- 🎯 想了解详细的信号过滤原因
- 🎯 需要真实市场数据

**运行方式**：
```bash
# 通过统一入口
python run_backtest.py  # 选择 [1]

# 或直接运行
python 真实回测_5年增强版.py

# 带调试模式
python 真实回测_5年增强版.py --debug

# 自定义参数
python 真实回测_5年增强版.py --years 3 --symbols EURUSD GBPUSD USDJPY
```

### 模式 2: 高速并发回测版

**特点**：
- ⚡ 并发 API 调用（10-100倍速度提升）
- ⚡ 智能缓存系统
- ⚡ 三种速度模式
- ⚡ 适合频繁测试

**三种速度模式**：
```bash
# cache 模式：建立缓存（第一次运行，5-10分钟）
python 一键回测_高速版.py --mode cache

# fast 模式：使用缓存（2-5分钟，10-30倍速）
python 一键回测_高速版.py --mode fast

# ultra-fast 模式：纯量化（30秒，100倍速）
python 一键回测_高速版.py --mode ultra-fast
```

### 模式 3: 标准回测版

**特点**：
- 📊 完整 8 组件系统
- 📊 90 天标准回测
- 📊 适合快速验证

**运行方式**：
```bash
python 一键回测完整版.py
```

## 🔧 配置 API 密钥

### 方法 1: 交互式配置（最简单）

直接运行脚本，系统会自动提示：

```bash
python run_backtest.py  # 选择 [1]

# 如果未检测到 API 密钥，会提示：
未检测到 OPENAI_API_KEY

请选择:
  [1] 粘贴 API 密钥（仅本次使用）
  [2] 粘贴并保存到 .env 文件（推荐）
  [3] 跳过（使用纯量化模式，不调用 LLM）
```

### 方法 2: 创建 .env 文件

在项目根目录创建 `.env` 文件：

```bash
OPENAI_API_KEY=sk-your-key-here
```

### 方法 3: 检查 API 密钥配置

不确定密钥在哪里？运行诊断工具：

```bash
python run_backtest.py  # 选择 [4]

# 或直接运行
python check_api_key.py
```

会显示：
- ✅ 环境变量位置
- ✅ .env 文件位置
- ✅ 虚拟环境配置
- 🔒 密钥前 10 位和后 4 位（安全显示）

## 🐛 常见问题

### Q1: 运行后显示 "没有执行任何交易"

**原因**: 你可能在运行旧的脚本（`一键回测完整版.py`）

**解决方案**:
```bash
# 使用统一入口，选择 [1] 真实回测 5 年增强版
python run_backtest.py

# 或直接运行新版本
python 真实回测_5年增强版.py --debug
```

### Q2: 找不到 src 模块

**原因**: 不在项目根目录

**解决方案**:
```bash
# 确认当前目录
pwd  # 或 cd

# 应该看到 src/ 目录
ls

# 如果没有，切换到正确目录
cd 解压后的目录名
```

### Q3: API 调用失败

**检查 API 密钥**:
```bash
python check_api_key.py
```

**GPT-5 兼容性**:
- ✅ 已修复 `max_completion_tokens` 参数
- ✅ 已修复 `temperature=1` 限制

### Q4: 想使用真实数据但没有 MT5

**不用担心**！系统会自动回退到高质量模拟数据：

```bash
# 会自动使用模拟数据
python 真实回测_5年增强版.py
```

或强制使用模拟数据：

```bash
python 真实回测_5年增强版.py --simulated
```
